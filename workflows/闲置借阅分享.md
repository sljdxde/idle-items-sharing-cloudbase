# Workflow: 闲置借阅分享（Idle Item Borrow & Share Loop）

> 来源：/improve-codebase-architecture + /loop-me + /grilling（候选③）。
> 定义即完成（done）：一个实现 agent 无需再问任何问题即可落地。

## 概述
一个 Item 从上架 → 被借 → 归还 → 再分享的往复 loop。核心 Trigger 是"借阅人发起借阅请求"，两个人工 Checkpoint 都是**物主 PIN 确认**。

状态机：`available → requested → borrowed → available`

## Trigger（触发）
- **事件触发**：浏览页某 `available` Item 的「我想借」被点击。
- （上架本身是独立 trigger：物主在 publish.html 填表 → 代理 `create` Item。本 workflow 聚焦"借—还"loop。）

## 角色
- **Borrower（借阅人）**：轻量身份（昵称 + 联系方式），无需登录。
- **Owner（物主）**：凭 PIN 管理，经代理鉴权。

## 步骤（含 Push right）

1. **[系统] 借阅人点击「我想借」** → 弹出轻量表单（昵称 / 联系方式 / 留言），可预填。
2. **[系统] 借阅人提交** → 前端调代理 `POST /api/items/:id/request`（body 含 BorrowRequest）。
   - 代理：校验字段 → 生成 `request.id` / `createdAt` → 追加进 `Item.requests[]` 且 `status:'pending'` → 将 `Item.status` 置 `requested` → **发一条 Issue 评论**（含借阅人昵称 + 留言）触发物主 GitHub 通知 → 返回成功。
   - **Push right**：通知与状态变更由系统一次完成，物主无需预处理。
3. **[Checkpoint · 物主]** 物主在 GitHub 收到评论通知（或在管理弹窗看到 pending）。打开管理弹窗输 PIN → 看到 pending 请求列表 → 选「确认借出」或「拒绝」。
   - 确认借出：代理 `setStatus(id,'borrowed')`，该 `request.status='accepted'`。
   - 拒绝：代理将该 `request.status='rejected'` 并从 pending 视图移除；若无其他 pending，`Item.status` 回 `available`。
   - **Brief（给物主）**：决策摘要——"XX 想借《物品名》：留言… ［确认借出｜拒绝］"，附 Item 链接。
4. **[系统] 借出中**：Item 显示「已借出」，「我想借」禁用。
5. **[Checkpoint · 物主]** 借阅人归还实物后，物主打开管理弹窗输 PIN → 「确认归还」。
   - 代理 `setStatus(id,'available')`，Item 回到可借（= **再次分享**，复用同一 listing）。
   - **Brief**："《物品名》已归还，已恢复为闲置中。"
6. **[系统] 再分享**：Item 重新出现在浏览页可被借，loop 闭环。

## 取消 / 边界
- 借阅人在 pending 时可**取消**自己的请求（代理 `request.status='cancelled'`；若无其他 pending，`Item.status` 回 `available`）。
- 物主可**拒绝**请求（见步骤 3）。
- **不设超时**：pending 请求一直挂着，物主管理弹窗列出全部 pending。

## 依赖 / 前置
- ItemStore 接口与 GitHubIssuesAdapter（ADR-0001、候选①②）。
- 代理端点：
  - `POST /api/items/:id/request`
  - `POST /api/items/:id/confirm-borrow`
  - `POST /api/items/:id/confirm-return`
  - `POST /api/items/:id/request/:rid/cancel`
  - `POST /api/items/:id/request/:rid/reject`
- PIN 加密校验在代理内完成（候选③ grill 结论）。

## 非目标（本轮未做）
- 真实用户身份（GitHub OAuth，候选⑤）——当前借阅人为轻量标识。
- 图片存储优化（候选⑥）。
- 多借阅排队 / 超时自动失效。
