# ADR-0004: 管理口令 + 借阅凭证替代「手机号即身份」

- **状态**：Superseded
- **日期**：2026-09-01
- **关联**：ADR-0001（薄代理持有 GitHub Token）

## Context（背景）

公网暴露后，「登录」只是把 11 位手机号写入 `localStorage`，写接口再把同一个号当 `operatorPhone` 校验。公开快照 / GitHub Issue 里还有明文 `ownerPhone` / `borrowedBy`。攻击者复制号码即可删除、下架、冒领、假归还。

曾考虑用 6 位管理口令 / 借阅凭证 + HMAC（`PIN_PEPPER`）替代手机号鉴权。

## Decision（决策）

**已撤销。** 产品选择继续用手机号登录作为写凭证，避免用户忘掉一次性口令、换设备无法管理。

仍保留 ADR-0001 的代理护栏：Origin 白名单、只操作带 `item` 标签的 Issue、字段/图片 URL 白名单、分路由限流、关闭评论写通道。已借出允许下架，不允许删除。

## Consequences（后果）

- 换设备只需登录同一手机号。
- 公开快照仍含身份电话，知道号码即可冒充；这是明确接受的产品折中。
- 坐标仍四舍五入到约 110m；图片 URL 仍走白名单。
